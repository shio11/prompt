# 役割
あなたは優秀なPythonエンジニアです。以下の要件に従って、tkinterを使ったGUI付きExcel転記アプリのPythonファイル（ファイル名: excel_transfer_app.py）のコードを作成してください。

# 目的
複数支店の経費明細（別ファイルの複数シートに分かれている）をGUIでチェックボックス選択して読み込み、内容を確認した上で、転記先のExcelテンプレートに書き戻す。

# 対象ファイル・仕様
- 転記先テンプレート: ./template.xlsx
  - シート「設定」: A列=資料キー、B列=資料名（表示用）、C列=読込対象（TRUE/FALSE）、D列=入力元ファイル名、E列=入力元シート名。データ行は4〜6行目（資料A/B/C）。
  - シート「サマリー」: B3=作成日、B4=作成者（Pythonが出力時に書き込む）。7〜9行目に資料ごとの小計（SUMIFS数式）、10行目に総合計（SUM数式）。これらの数式セルはPython側から書き換えない。
  - シート「明細」: ヘッダー行3（資料名/日付/費目/金額）、4行目以降にデータ行。出力時はこの4行目以降を全削除してからGUI表示内容で書き直す。
- 入力元ファイル: ./source_data.xlsx（テンプレートとは別ファイル。パスは「設定」シートD列に記載されているものを使う）
  - シート名は「設定」シートE列の値と対応する（例: 資料A_東京支店）
  - 各シート: 3行目がヘッダー（日付/費目/金額）、4行目以降がデータ

# GUIの仕様
1. アプリ起動時に、template.xlsxの「設定」シートを自動で読み込み、資料ごとにチェックボックス（Checkbutton、初期状態は設定シートC列のTRUE/FALSE）を並べて表示する。
2. チェックボックスの状態を変更したら、ボタン操作なしで即座に、チェックON中の資料についてsource_data.xlsxの対応シートから明細を読み込み、GUI上の一覧（Treeview）に「資料名／日付／費目／金額」で再表示する。チェックOFFの資料は一覧から除外する。
3. 一覧の下に現在表示中の合計金額（チェックON資料の金額合計）をラベル表示し、チェック状態変更のたびに再計算する。
4. 「Excelに出力」ボタンを押すと、その時点で一覧に表示されている明細行をtemplate.xlsxの「明細」シートに書き込み、保存する。書き込み前に上書き確認のメッセージダイアログ（messagebox.askyesno）を出す。
5. 保存成功時／失敗時にそれぞれメッセージダイアログで通知する。

# 入出力の仕様
- 入力: template.xlsx（設定・GUI初期表示用）、source_data.xlsx（明細データ本体）
- 出力: template.xlsx（同ファイルに上書き保存。「明細」シートのデータ行のみ更新し、「サマリー」シートの数式・「設定」シートの内容は変更しない）

# 詳細な要件・機能
1. openpyxlを使用してExcelの読み込み・書き込みを行う。読み込みは数式を保持したまま（data_only=Falseのデフォルト）扱い、サマリーシートの数式セルには一切書き込まない。
2. tkinterでウィンドウ、Checkbutton、Treeview（一覧表示）、Label、Buttonを配置する。レイアウトはgrid()で統一する。
3. チェックボックスの状態管理にはtkinter.BooleanVarを使用し、traceまたはCheckbuttonのcommandコールバックで状態変更を検知する。
4. 「設定シートの読み込み」「source_dataからの明細読み込み・集計」「Treeviewへの反映」「template.xlsxへの書き込み」をそれぞれ独立した関数に分離し、値の計算部分（明細のフィルタリング・合計計算）は副作用のない純粋関数として実装する。
5. 例外処理を実装する（template.xlsxまたはsource_data.xlsxが存在しない、指定シートが見つからない、書き込み時に対象ファイルが他アプリで開かれている、など）。いずれもエラーメッセージをmessagebox.showerrorで表示し、アプリを異常終了させない。
6. 型ヒントを付与する（Excelから読み込む値はUnion[str, int, float, None]など実態に即した型で明示し、anyやAnyは使わない）。
